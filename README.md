# 📝 会议纪要整理器（Meeting Minutes）

把杂乱的会议记录粘贴进来，一键生成结构化的会议纪要：**议题 / 结论 / 待办事项（负责人 + 截止日期）**，可直接复制为 Markdown 或下载 `.md` 文件。

纯前端实现，**零依赖、离线可用**，所有数据仅在本机浏览器内处理，不会发送到任何服务器。

## ✨ 功能特性

- 🧠 **智能解析**：识别「主题 / 议题 / 结论 / 待办 / TODO」等前缀，无前缀的行按关键词自动归类
- 👤 **自动提取负责人**：识别 `@姓名` 格式
- 📅 **自动提取截止日期**：支持 `2026-10-25`、`10月20日`、`10/20`、`下周三前`、`20号前` 等多种写法
- ✏️ **结构化编辑**：解析结果可在线增删改，实时同步到 Markdown
- 📋 **一键导出**：复制到剪贴板，或下载 `.md` 文件（文件名自动带主题与日期）
- 🔒 **隐私安全**：无后端、无网络请求、无 Cookie，断网也能用
- 📱 **响应式布局**：桌面与手机均可使用

## 📝 使用说明

1. 在左侧粘贴会议原始记录（口语化文本即可，支持点击「填入示例」体验）
2. 点击「生成结构化纪要」
3. 在右侧「编辑」选项卡中检查、增删改内容
4. 切换到「Markdown 预览」，复制或下载

### 识别规则示例

```
主题：Q4 产品迭代计划评审
议题1：新版首页上线时间
结论：同意 11 月 1 日灰度发布新版首页
待办：@张三 准备灰度发布方案 10月20日
TODO：@李四 整理用户反馈，下周三前
```

解析结果：

| 内容 | 负责人 | 截止日期 |
| --- | --- | --- |
| 准备灰度发布方案 | 张三 | 10月20日 |
| 整理用户反馈 | 李四 | 下周三前 |

## 🛠️ 技术说明

- 无任何框架与构建步骤，原生 HTML / CSS / JavaScript
- 解析引擎暴露在 `window.MeetingMinutes` 上，便于测试与二次开发：

```js
const data = window.MeetingMinutes.parseRawText(rawText); // 解析原始记录
const md = window.MeetingMinutes.toMarkdown(data);        // 生成 Markdown
```
